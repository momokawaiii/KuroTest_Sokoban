# 谐振：失序符文

基于 Unreal Engine 的三维推箱解谜工程，包含五个关卡和符文关卡编辑器。

## 打开工程

1. 在 Windows 安装 Unreal Engine 5.8.4、C++ 编译工具链和 Git LFS。
2. 克隆仓库，在工程目录运行 `git lfs pull` 获取关卡和其他资产。
3. 打开 `ResonantRunes.uproject`。首次打开时按提示重建模块。若提示找不到引擎，右击项目文件，选择 **Switch Unreal Engine version** 并关联本机的 UE 5.8。

## 游玩关卡

在默认地图 `L_Puzzle` 点击 UE 工具栏的 **播放**。在 SP 预算内移动和施法，使所有阵眼的条件成立。通关后按 `Enter` 进入下一关。完成最后一关后显示完全胜利。

| 输入 | 操作 |
| --- | --- |
| 点击角色或按 `Space`，再点亮起的格子 | 在总览中走一格，消耗 1 SP |
| `W` `A` `S` `D` / `F` | 在第一人称中移动 / 返回总览 |
| 滚轮 / 按住 `E` | 缩放总览 / 显示被遮挡的阵眼和移动提示 |
| `Tab` / `G` | 切换同格目标 / 解除自身风托并落地 |
| `Z` / `R` | 撤销一步 / 重试本关 |

按数字键装备本关开放的技能。电推需长按左键，其余技能瞄准后单击左键。

| 键 | 技能 | 作用 | SP |
| --- | --- | --- | --- |
| `1` | 极电千鸟 | 沿视线推箱一格。受风托或已水锚的箱子可竖推 | 2 |
| `2` | 抟风九万 | 抬箱一层，风托持续两回合。瞄准脚下可免费抬升角色 | 3 |
| `3` | 沦灭潭渊 | 给箱子施加水锚，使它免于重力下落，仍可电推和风抬 | 2 |
| `4` | 镜花水月 | 将箱子或障碍转为 Hiss，使其可与普通箱同格 | 2 |

## 编辑关卡

从 **工具 → 符文关卡编辑器** 打开。悬停设置可查看中文说明。

| 功能 | 操作 |
| --- | --- |
| **关卡列表** | 点 **新建** 填写名称、网格尺寸和可选的 `DA_Puzzle_` 后缀。拖动列表行调整接关顺序，按 `F2` 修改显示名。在 **关卡设置 → 棋盘资产名** 可重命名现有资产。 |
| **棋盘视口** | 切换 **等距** 或 **顶视**，用 `PgUp` / `PgDn` 切换 Z 层，点眼睛图标隔离当前层。选择放置工具后左击棋盘。用 **选择** 工具移动元素或修改坐标，按 `Delete` 删除。 |
| **元素属性** | 出生点需地板或障碍顶面支撑，可左转或右转 90°。符文箱可设置编号、Hiss 相态、PhaseLock 锁高（水锚）和风托回合。阵眼可接受符合条件的任意箱子或指定编号，也可要求水锚或普通箱与 Hiss 箱叠合。 |
| **关卡设置** | 可设置格宽、世界原点、初始 SP、可用技能和入场提示。应用较大的尺寸会为新增的 Z0 格铺地板。缩小时在顶视图拖选保留范围，再点 **应用裁剪**。 |
| **保存与试玩** | 用 `Ctrl+Z` 和 `Ctrl+Y` 撤销或重做。点击 **校验** 检查棋盘数据，**保存** 写入资产，**试玩** 从当前关卡开始。 |

第三方素材按各自许可使用。共享可编辑资产时，遵守对应的源格式分发条款。[Epic 内容许可协议](https://www.unrealengine.com/eula/content) · [Fab 许可协议](https://www.fab.com/eula)
